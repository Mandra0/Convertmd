# Universal Markdown Converter

A web application utilizing the Streamlit interface and the MarkItDown library. It performs batch conversion of various document types (PDF, Word, Excel, PPTX) into a single Markdown format ready for AI models to read.
ID Aplikasi web menggunakan antarmuka Streamlit dan pustaka MarkItDown. Berfungsi untuk mengonversi berbagai tipe dokumen secara massal (PDF, Word, Excel, PPTX) menjadi format Markdown tunggal yang siap dibaca oleh model AI.
